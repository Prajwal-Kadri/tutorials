# Tutorials

This repository contains a static, multi-page website themed around dogs.

## Project Summary

- Frontend-only project (HTML, CSS, JavaScript/jQuery)
- Main pages:
  - `index.html` (home with slider)
  - `about.html`
  - `picture.html` (gallery with prettyPhoto)
  - `contact.html` (map + contact form layout)
- Assets are in `images/`, styles in `css/`, and scripts in `js/`

## Run Locally

Open `index.html` in a browser, or serve the repository root with any static file server.
