# Tutorials

This repository contains a static, multi-page website themed around dogs.

## Project Summary

- Pure frontend project (HTML, CSS, JavaScript/jQuery)
- Main pages:
  - `index.html` (home with slider)
  - `about.html`
  - `picture.html` (gallery with prettyPhoto)
  - `contact.html` (map + contact form layout)
- Assets are stored under `images/`, styles under `css/`, and scripts under `js/`

## Run Locally

Open `/home/runner/work/tutorials/tutorials/index.html` in a browser, or serve the repository root with any static file server.
