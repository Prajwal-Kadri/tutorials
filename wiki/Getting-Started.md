# Getting Started

## Prerequisites

No build tooling is required. This is a static website.

All you need is:

- A web browser
- (Optional) A local static file server for cleaner testing

## Run locally

### Option 1: Open directly

Open `/home/runner/work/tutorials/tutorials/index.html` in your browser.

### Option 2: Serve over HTTP (recommended)

From the repository root (`/home/runner/work/tutorials/tutorials`), serve files with any static server and open the served URL in your browser.

## Main user flows to verify

- Home page navigation
- About page copy and hero image
- Pictures page gallery lightbox behavior
- Contact page map embed and form layout

## Editing basics

- Update styling in `css/style.css`
- Update gallery/lightbox styling in `css/prettyPhoto.css`
- Update slider behavior in `js/easySlider1.7.js` and inline script on `index.html`
- Update gallery behavior in inline script on `picture.html`
