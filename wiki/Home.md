# Tutorials Wiki

Welcome to the wiki for the `Prajwal-Kadri/tutorials` repository.

## What this project is

This project is a static website built with:

- HTML pages (`index.html`, `about.html`, `picture.html`, `contact.html`)
- CSS styles in `css/`
- jQuery-based UI scripts in `js/`
- Image assets in `images/`

The current site theme and copy focus on a dog-themed website (including a photo gallery and contact page).
